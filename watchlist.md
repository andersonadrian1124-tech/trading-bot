# Crypto Watchlist

Coins/tokens to include in the daily 7am update. Add or remove lines as needed.

For each coin, the daily update should define/maintain a pair of scenario
levels (not price targets — structural levels where the read would change):
- **Continuation level**: what holding above/support would confirm
- **Breakdown level**: what breaking below with rising volume would suggest

Update these levels as price action develops. Flag in the daily update when
either level gets hit.
